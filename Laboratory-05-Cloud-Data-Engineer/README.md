# Laboratory Activity 05: The Cloud Data Engineer

## Mission Overview
This laboratory activity focuses on understanding cloud storage paradigms and deploying an S3-compatible Object Storage server (MinIO) using Docker[cite: 1]. The objective is to provide a persistent storage solution for a client application decoupled from ephemeral compute containers[cite: 1].

## Objectives
* Differentiate between Block, File, and Object storage paradigms[cite: 1].
* Deploy a MinIO Object Storage server container using Docker environment variables[cite: 1].
* Port-forward and access the cloud service web console on port 9001[cite: 1].
* Create storage buckets and upload object assets[cite: 1].
* Document operational steps and submit repository evidence[cite: 1].

## Tools Used
* **Docker Engine** (Containerization platform)[cite: 1]
* **MinIO** (S3-compatible Object Storage server)[cite: 1]
* **KillerCoda Playground** (Ubuntu/Docker environment)[cite: 1]
* **Git & GitHub** (Version control and portfolio hosting)[cite: 1]

## Skills Learned
* Deploying containerized services with custom environment variables (`-e`)[cite: 1].
* Configuring cloud storage buckets and object-level permissions[cite: 1].
* Selecting appropriate storage solutions based on application architecture and performance requirements[cite: 1].
