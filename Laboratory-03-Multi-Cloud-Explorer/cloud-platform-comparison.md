## Research Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of services due to its first-mover advantage and continuous investment in new cloud categories. Its ecosystem features over 200 fully featured services ranging from core infrastructure to specialized edge tools.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best integration with Microsoft technologies because it is natively built to support Windows Server, Active Directory, and Microsoft 365. Organizations can seamlessly extend existing licensing and enterprise credentials into the Azure cloud.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is the strongest in Artificial Intelligence and Kubernetes because Google originally created Kubernetes and built GCP on advanced data-processing technologies. GCP provides dedicated AI hardware like TPUs and deeply integrated tools like Vertex AI and Google Kubernetes Engine (GKE).

### 4. Which cloud platform would you personally choose and why?
I would choose Google Cloud Platform (GCP) because of its developer-friendly environment and superior container orchestration tools. GKE makes managing microservices straightforward, and its strength in data analytics and AI provides a strong foundation for building modern applications.
