# Laboratory 03: Multi-Cloud Explorer

## Overview
This laboratory activity explores the core architectures, services, and trade-offs among the three leading cloud service providers: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## File Structure
- `aws-research.md` - Research report on AWS features and core services.
- `azure-research.md` - Research report on Azure capabilities and enterprise solutions.
- `gcp-research.md` - Research report on GCP infrastructure, AI tools, and Kubernetes.
- `cloud-platform-comparison.md` - Side-by-side comparison tables and service equivalencies.
- `client-recommendations.md` - Real-world scenario analysis and multi-cloud decision matrix.
- `reflection.md` - Insights and key takeaways from acting as a Cloud Solutions Consultant.

## Checkpoint 7: Linux Server Investigation (KillerCoda Playground)

### System Discovery Output

Commands executed on the Linux virtual instance:
- `uname -a` - Kernel and system platform details
- `lscpu` - CPU architectural details
- `free -m` - Memory usage breakdown in megabytes
- `df -h` - Disk file system storage usage in human-readable format

### Cloud Migration Analysis

If this KillerCoda Linux server were migrated to the cloud, it could be hosted using the following equivalent infrastructure services:

- **AWS:** Amazon Elastic Compute Cloud (Amazon EC2) instance
- **Microsoft Azure:** Azure Virtual Machine (Linux distribution)
- **Google Cloud Platform:** Google Compute Engine (GCE) instance
