```markdown
# Laboratory Activity 1: Welcome to the Cloud

* **Student Name:** JERSON V. ACOSTA
* **Course & Section:** CCM101 - Cloud Computing
* **Institution:** University of Eastern Pangasinan

---

## Mission Overview
This onboarding mission serves as an introduction to working inside a cloud-based Linux environment, gathering essential system diagnostics, building standardized folder structures, and documenting technical workflows using Markdown and GitHub.

---

## Objectives
* Access a cloud-based Linux environment using KillerCoda.
* Explore and navigate the Linux file system via CLI.
* Gather key system and hardware specifications.
* Organize directories and files using standard Linux terminal commands.
* Establish a professional GitHub portfolio for course deliverables.

---

## Activities Performed
1. **Cloud Environment Provisioning:** Launched an Ubuntu 24.04 instance on KillerCoda and created a user account (`jacosta`) with sudo privileges.
2. **System Investigation:** Queried hardware specs, OS release details, memory allocations, and storage limits.
3. **Workspace Configuration:** Built nested directory structures (`Documents`, `Notes`, `Reports`, `Screenshots`) inside the home directory.
4. **Documentation & Version Control:** Authored technical `.md` documentation files and published the work to GitHub.

---

## Linux Commands Used
* `useradd` / `usermod` / `passwd` — Created and configured the user account `jacosta`.
* `su -` — Switched to the newly created user session.
* `mkdir -p` — Generated directory structures.
* `cat` / `uname` / `lscpu` / `free` / `df` — Inspected system specifications and specs.
* `nano` — Authored and edited text/Markdown files.

---

## Skills Learned
* Managing user sessions and privileges in an Ubuntu Linux environment.
* Extracting hardware and system details using terminal diagnostics.
* Writing clean technical documentation using Markdown syntax.
* Structuring and managing a version-controlled portfolio repository on GitHub.

```
