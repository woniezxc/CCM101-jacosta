# Cloud Provider Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
| :--- | :--- | :--- | :--- |
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 / EBS | Azure Blob / Disk Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network (VNet) | VPC Service |
| Identity & Access Management (IAM) | AWS IAM | Microsoft Entra ID (Azure AD) | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of cloud services globally. Because AWS was the pioneer in public cloud infrastructure, it has accumulated the largest ecosystem of tools covering compute, storage, databases, IoT, and developer utilities.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is highly recommended for organizations relying heavily on Microsoft products. Azure provides native integration with Active Directory (Entra ID), Windows Server licenses, SQL Server, and Microsoft 365, making hybrid deployments and licensing seamless.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized for AI, Machine Learning, and Kubernetes services. Google originally developed Kubernetes (GKE) and TensorFlow, giving GCP an advantage in container management and data processing capabilities.

### 4. What similarities did you observe among the three cloud providers?
All three cloud providers offer equivalent core infrastructure capabilities including scalable compute instances, object and block storage, virtual private networking, and identity management. They also share pay-as-you-go pricing models and global infrastructure regions for deployment reliability.
